# 移动端阅读与课程词表复用

## 本轮修改

### 课程简介

首页「新建课程」和后台课程管理统一支持可选简介，最大 5,000 个字符。省略简介、空字符串、纯空格及 `null` 均可正常创建；编辑时省略该字段保留原值，主动清空则保存为空字符串。

原问题来自 Laravel 将空字符串转换为 `null`，与接口 `string` 校验冲突。两个创建入口现在使用同一持久化方法，并记录创建审计。

### 手机字幕阅读

- 900px 及以下默认折叠课堂信息、管理操作和回放，摘要保留连接状态和时长。
- 字幕模式选择、大字幕入口、阅读设置放在正文工具栏。搜索、历史加载、字号和自动跟随按需展开。
- 手机上默认收起逐条字幕编辑工具；在阅读设置中可开启。异常字幕状态仍显示。
- 普通阅读支持 16/18/20/24/28px 字号并记忆偏好；大字幕继续支持 24/32/40/48/64px。
- 大字幕模式使用动态视口的剩余高度，保留录音暂停/结束操作。录音交接组件保持挂载，传入邀请仍可弹出。
- 每帧最多执行一次跟随滚动；翻阅历史或选择文字后暂停跟随。退出大字幕、修改字号或横竖屏切换时，正在跟随的页面保持在最新内容。
- 使用短时透明度和位移动画，不对流式文字更新反复播放入场效果；系统要求减少动态效果时不启用这些动画。
- 弹窗删除重复的界面语言选择；登录、创建等弹窗删除重复标题，打开后优先聚焦输入项。

普通手机布局使用 `100dvh` 减去顶部操作区来分配正文高度，横屏也可进入大字幕模式。实际设备效果仍需按下方浏览器测试确认。

### 复制专业词表

后台 → 专业术语表 → 选择来源课程 →「复制词表到其他课程」→ 选择目标课程并确认。

复制全部未删除词条，不受当前筛选或分页影响，保留语种、备注和启用状态。目标中已有相同原文及目标语言的条目会跳过，保留目标译法。不同源语言也使用这一冲突规则，因为模型对每种目标语言只接受一个原文键。

接口：`POST /api/admin/courses/{target}/glossary/copy`

```json
{
  "source_course_id": 1,
  "expected_glossary_version": 7,
  "confirmed": true
}
```

需要管理员权限和近期身份验证。返回新增数量、跳过数量及目标词表新版本。两个课程按 ID 顺序加锁，合并、容量校验、版本更新和审计位于同一事务；目标版本过期返回冲突，超限时全部回滚。已开始课堂的词表快照不变，新课堂首次收音时采用更新后的词表。

```sh
pnpm install --frozen-lockfile

pnpm test

```
