## 导入与生效

服务器原有该课程术语数量为 0、版本为 1。导入通过应用 `Glossary::save` 服务执行，复核启用管理员、锁定课程、检查预期版本，254 条保存和审计记录在同一个外层事务提交。版本最终为 255。现有条目遇到相同源词时保留；不同对应词会导致整批回滚，不覆盖原有内容，也不自动启用或恢复管理员禁用、删除的术语。

课程术语的既有生效规则为 `next_lesson_first_start`：新建课堂首次开始录音时冻结术语快照。已开始课堂的旧快照不热更新，暂停后恢复录音也继续使用原快照。服务器既有课堂快照本次均未改变。

导入前课程、术语及既有快照备份在服务器 root 私有文件 `/www/server/clt-deploy-private/20261010-aviation-glossary/before.json`（权限 600；父目录 700）。同目录保存导入脚本、目录数据与三份实际运行报告。备份不包含用户密码、环境变量或云服务密钥。

若需要回退，应先核对该目录 `apply-v1.json` 的新增术语 ID 与当前版本，再通过 `Glossary::deletion` 服务逐条软删除，仅回退此次新增条目。这样保留审计历史和已经冻结的课堂快照；不得直接恢复整个数据库覆盖后续课堂及管理员修改。
