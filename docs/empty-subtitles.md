# 空白识别结果过滤 · 2026-10-10

用户反馈模型的空白原文、译文会生成占屏的字幕卡片。此前网关把所有 `subtitle.upsert` 的文本直接入库，空字符串也会成为已确认记录。

现在网关拒绝为空、仅空格/换行、全角空格、NBSP或常见零宽/方向控制字符的文本。原文和译文分别检查：有内容的独立译文仍保留，标点、数字0、中文、英语和乌克兰语均不会被误判。真实文本保留原样，不通过修剪改写模型原文。

如果先出现非空的未确认草稿、随后模型返回空白最终结果，撤回该草稿并发送带删除标记的字幕事件，让所有观看客户端移除它；已确认原文和人工校对结果不会被迟到的空白元数据覆盖。

已有空白记录在HTTP/WSS快照、历史分页、时间定位、课程搜索、后台字幕列表和导出时过滤。过滤在分页和总数计算前执行，空行不会占据页面名额。历史数据库行保留；已校对为有效文字的行仍显示。前端缓存合并、断线事件恢复和回放高亮另有相同的显示保护。人工校对也不能写入纯空白文本。
