# 课堂同声传译网站：完整开发提示词

> 需求修订：2026-10-08。明确每节课右上角二维码分享入口，细化大字幕模式，并将字幕导出列为首版必做功能。二维码绑定具体课堂，不跳转到同一课程后来新开的其他课堂。

## 给开发代理的总指令

你是一名负责交付可部署产品的全栈工程师。请根据本文实现一个用于大学外教课堂的同声传译网站。核心流程为：一位获授权的用户通过设备麦克风收音，PHP 服务端将音频送入 Qwen 实时翻译模型，将原文与译文流式共享给同一课堂中的所有观看者，并保存课堂原声录音、字幕及完整校对历史，供课后回顾。

请直接实施，不要只交付产品方案、静态原型、伪代码或模拟聊天界面。存在仓库时先检查现有代码与部署方式，再增量实现；不存在仓库时建立结构清晰的项目。先打通“收音—模型—多人字幕—保存—回放”纵向闭环，再完成管理与体验功能。

本文包括用户原始要求与为消除歧义补充的默认规则。未标注“二期”的内容属于首版范围。不可擅自删除原始需求，也不可为了二期功能拖延核心交付。外部账号、密钥或设备缺失时，完成可独立实现的部分，并准确标注尚未实测的项目；不得将模拟测试冒充真实模型、真实 OSS 或真实移动设备验证。

## 一、技术边界与系统结构

### 1. 强制要求

- 业务后端使用 PHP，数据库使用 PostgreSQL，不得用 MySQL 或 SQLite 替代生产数据库。
- 文件存储使用阿里云 OSS，通过标准 S3 兼容接口访问，不依赖 OSS 私有文件存储 SDK 才能完成核心存取。
- 实时翻译模型默认使用 `qwen3.8-livetranslate-flash-realtime`。模型名称、地域、Workspace ID、WebSocket Endpoint、API Key 均可配置。
- 网站需要适配手机、平板和笔记本，全部用户界面支持简体中文、英语、乌克兰语。
- 每节课详情右上角必须有二维码图标和语言选择入口；二维码分享、大字幕模式、字幕导出均为首版必做功能，详见第十四节。
- 首版主要提供实时文字字幕以及课堂原声回放，不默认生成或播放翻译后的合成语音，不默认启用声音克隆、摄像头或视觉输入。

### 2. 推荐实施结构

默认采用以下方案，选择彼此兼容且仍受维护的版本，并提交依赖锁文件：

- Laravel：HTTP API、用户与权限、后台管理、数据库访问、业务状态变更、队列任务。
- Workerman：PHP 常驻 WebSocket 网关，处理浏览器音频接入、Qwen 上游 WebSocket 连接和课堂事件广播。
- Vue 3 + TypeScript + Vite：响应式前端，配套完整国际化方案。
- PostgreSQL：持久化业务数据、最终字幕、编辑历史、录音索引和审计记录。
- Redis：在线状态、短期缓存、限流、任务与跨进程通知；不得成为最终字幕和权限历史的唯一存储。
- FFmpeg：服务端录音封装、拼接及转码。
- Nginx + HTTPS/WSS：对外统一入口。

Node.js 可用于前端构建，但不要把核心业务、实时音频网关或模型代理改成 Node.js/Python 后端。PHP 常驻服务必须与普通 HTTP 请求生命周期分离，不能在 PHP-FPM 请求中无限循环实现整堂课的模型连接。

使用模块化单体加独立实时进程即可，首版不需要 Kubernetes、复杂微服务或商业实时消息平台。不要同时引入多套功能重复的 WebSocket 广播系统。

### 3. 数据流

收音设备麦克风 → 浏览器采集与重采样 → 本站 PHP WebSocket 网关。

网关将同一份有效音频分别交给持久化录音路径和 Qwen 上游连接。

Qwen 事件 → 服务端解析、归段与持久化 → 同课堂用户实时订阅。

录音片段 → 异步封装与上传 → 私有 OSS 对象 → 经网站授权后的回放链接。

同一课堂、同一目标语言正常情况下只维护一条有效实时翻译链路。观看人数增加时只增加字幕广播，不得为每位观众单独调用模型。重新连接或会话轮换可以产生顺序衔接的新上游会话，但不得因此同时重复处理同一段音频。

## 二、首版业务默认规则

1. 首版以一个班级共享使用为主，不扩展为复杂的多租户平台。
2. 网站层级固定为“课程 → 课堂 → 课堂原声、原文与译文”。课程例如空气动力学、大学物理；课堂例如第一节课、第二节课。
3. 同一课程最多存在一个未结束课堂，未结束包含待开始、进行中和暂停；不同课程可以各自存在活动课堂。
4. 课程由管理员创建和管理；普通用户可创建课堂，重命名其可访问的课堂，编辑其中已完成的字幕。不要未经说明把普通用户的重命名与校对权限限制为“只能操作自己创建的课堂”。
5. 当前收音者负责开始、暂停、继续与录音权交接。当前收音者、课堂创建者和管理员可以经确认结束课堂。管理员可以冻结字幕编辑并留下审计记录。
6. 普通用户不能删除课堂、删除句子、管理其他用户或修改系统设置。
7. 课堂默认翻译成中文。界面语言只改变界面文字，不改变课堂目标语言，不重新调用模型，也不重新翻译历史内容。
8. 老师原语言以模型实际支持的自动识别为默认方案，重点测试英语、乌克兰语和带俄语口音的英语。不得照搬其他模型版本的源语言参数；不支持手动指定时，应明确显示“自动识别”。
9. 同一课堂首版采用统一目标语言，可在创建前通过课程设置选择官方支持的文字目标语言，至少验证中文、英语和乌克兰语。课堂开始后不允许观众各自改变全班共享的目标语言。无法实测的语言方向不得标为已验证。
10. 暂停是临时停止收音，不等于结束课堂；结束后不得意外继续采集或计费。

## 三、角色、登录与安全边界

### 管理员 admin

拥有普通用户的全部能力，并可访问后台，管理课程、课堂、句子、用户、术语表和系统设置。管理员可以强制释放失效录音权或接管，但必须确认、通知课堂内用户并记入审计。管理员无法绕过其他设备的浏览器麦克风授权。

### 普通用户 user

只能由管理员单个添加或通过 Excel 批量导入。不能自助注册。可查看内容、创建课堂、重命名课堂、校对已完成字幕、申请/接受/转移录音权；完成强制改密且具有课堂访问权限后，可导出该课堂字幕。

### 游客 guest

无需登录即可查看允许游客访问的课程、课堂、实时字幕及历史回放，可以使用大字幕模式，以及展示、复制已经获准访问的该课堂分享链接或二维码。不得创建、重命名、校对、删除、请求录音权、接收转移邀请或发送音频；默认不得调用字幕批量导出接口，也不得创建、重置或延长分享令牌。

游客页面不得主动调用麦克风授权接口。必须在服务端 HTTP API、WebSocket 命令、音频接入口和管理接口同时执行权限校验，不能仅靠隐藏按钮。

### 游客访问范围

保留“无需登录可查看”的能力。课程支持公开访问和持有效分享链接访问两种模式，由管理员明确设置；新建课程默认为公开模式，以保留原始需求，并在后台提醒其可被非本班人员访问。分享链接模式不要求游客注册，但必须校验可撤销的随机访问令牌。

游客权限与用户角色分开判断，不能拿“游客可以看”作为所有课程永远公开的理由。关闭课程公开访问、撤销分享或删除课堂后，必须同步阻止新的订阅与回放授权。已发出的短期音频链接存在失效窗口，需要文档说明；严格即时撤销场景可使用受控代理。

### 登录与密码

- 以学号和密码登录，显示姓名；学号是字符串，不是整数。
- 普通用户初始密码严格按学号最后 6 个字符生成。少于 6 个字符的学号拒绝导入并说明原因。
- 使用安全密码哈希，禁止明文或可逆加密保存密码。
- 用独立的 `must_change_password` 状态标记强制改密，不通过简单比较密码内容判断。
- 首次登录或管理员重置后弹出不可跳过的改密弹窗。服务端同步阻止所有需要正式用户身份的操作，只允许改密、登出和必要的受限账户接口；公开内容可按游客权限阅读。
- 新密码不得与初始密码相同，不得继续使用学号本身；设置合理长度规则与登录限流。
- 登录页提供“90 天保持登录”选项。使用可撤销、可轮换、服务端保存哈希的设备级记住登录令牌，Cookie 设置 Secure、HttpOnly 和适当的 SameSite。
- 不得通过一个无法撤销的 90 天长期 JWT 或 localStorage 中的长期密钥实现。
- 提供修改密码、退出当前设备、退出全部设备。禁用账户、重置密码后必须撤销相关登录与 WebSocket 权限。
- 管理员账户通过安全初始化命令创建，不内置通用管理员密码；敏感设置变更要求重新验证身份。
- 学号后 6 位密码可预测，界面和部署文档必须提醒管理员及时完成首次改密。可以预留未来替换为一次性激活凭证的能力，但首版不能擅自改变用户指定的初始化规则。

## 四、响应式界面与三语言国际化

### 视觉与布局

采用扁平化设计，字幕阅读为中心。使用清晰排版、适量留白、细边框和有限强调色，避免重阴影、拟物效果、大面积装饰和与课堂无关的大型首页宣传区。

图标可使用 iconfont，确认授权后将必要 SVG/图标资源随项目发布，不依赖课堂现场加载第三方脚本。小人、麦克风、加号、铅笔、历史、播放、暂停、搜索、排序、二维码、大字幕/全屏、导出等图标语义一致。图标按钮有可访问名称与提示，不仅用颜色表达状态。

手机采用单列、底部安全区适配和便于点击的操作区；平板充分利用横竖屏及分屏；笔记本控制内容最大宽度，不把字幕横向拉得过长。需要处理软键盘、长姓名、乌克兰语长词、横屏和较小窗口，不出现整体横向溢出。建议交互目标至少 44 CSS 像素。

### 国际化

- 语言为 `zh-CN`、`en`、`uk`，乌克兰语语言代码不能误用 `ua`。
- 每个页面右上角都有“中文 / English / Українська”语言切换入口，包括登录页、后台、错误页和字幕展示模式。
- 覆盖菜单、弹窗、确认与取消按钮、占位符、错误提示、表单验证、空状态、时间与时长描述、在线状态、系统消息、导入结果及辅助文字。
- 避免组件内散落硬编码文案，建立完整语言资源和缺失键检测。后台返回稳定错误码与参数，由界面本地化显示。
- 使用覆盖中文、拉丁字母与西里尔字母的字体回退；验证 І、Ї、Є、Ґ 等乌克兰字符。
- 切换语言立即生效并保存偏好，不能中断收音、重建课堂、丢失草稿或跳回首页。
- 用户输入的姓名、课程名、课堂名和字幕本身不因界面切换而自动翻译。
- 数据库时间按 UTC 保存，网站展示时区可配置，默认 `Asia/Shanghai`；语言、时区和课堂字幕语言是不同设置。

## 五、课程主页和课堂列表

### 课程主页

首页显示课程列表，包含课程名称、简要说明、课堂数量和活动状态。正在进行或暂停中的课程置顶，状态同时显示文字与标记。

点击有进行中/暂停课堂的课程，直接进入该课堂；没有进行中课堂时进入课堂列表。提供独立的“全部课堂/历史课堂”入口，确保自动跳转不会妨碍查历史。

路由可采用 `/courses`、`/courses/{id}/lessons`、`/lessons/{id}`；具体实现可调整，但职责必须分清。

### 课堂列表

每个课堂至少显示名称、创建时间和课堂时长，另显示待开始/进行中/暂停/已结束状态。

支持按名称搜索，按名称、创建时间、时长切换排序字段，并分别控制升序/降序。支持状态筛选与分页，保留搜索和排序状态，排序使用稳定次级键，避免实时更新时列表无规律跳动。

列表中的“课堂时长”定义为有效录音累计时长，暂停时间不计入；实际录下的安静时间仍计入。详情另可显示开始至结束的经过时间，不能把两者混为一谈。未开始显示 00:00，活动课堂实时更新。

### 新建课堂

列表右上角对管理员和普通用户显示加号。点击后弹出“新建课堂”，包含一个课堂名称输入框，中文界面默认值为“新建课堂”，其他语言对应本地化默认值。底部按钮为“取消”“确认”。

确认后创建课堂并进入详情，创建者默认取得该课堂的业务收音权，初始状态为待开始。点击“开始”并获得浏览器授权后才真正录音，不能一创建就暗中采集。

使用服务端事务、幂等键和数据库约束处理重复点击与并发创建；已有未结束课堂时提示并允许直接进入，不创建重复活动课堂。

### 重命名

普通用户和管理员可以重命名其有访问权限的课堂。使用弹窗编辑名称、校验非空和长度，保存后广播更新，并记录修改人、修改前后名称与时间。

## 六、课堂状态、开始、暂停与结束

课堂业务状态采用清晰状态机，例如 `ready / live / paused / ended`。翻译连接状态与录音归档状态单独保存，不能用一个字段同时混合“暂停”“模型掉线”“正在转码”。

页面显示课程与课堂名称、课堂状态、当前收音者、在线人数、有效录音时长和连接状态。

每节课的详情页右上角固定提供独立二维码图标，与界面语言选择入口并列；待开始、进行中、暂停和已结束课堂均须提供。工具区另提供“大字幕模式”，并向具有导出权限的登录用户提供“导出字幕”。移动端不能把二维码和语言入口全部藏进更多菜单；导出等次级操作可收入清晰可达的更多菜单。所有角色看到的分享内容和操作权限须符合第十四节。

当前收音者底部显示开始/暂停/继续按钮和次级“结束课堂”操作。非收音者显示同步状态，已登录用户显示“申请录音权”；游客仅显示观看相关操作。

开始前提供本地麦克风检测、输入设备选择和音量指示。浏览器拒绝授权、无麦克风、设备占用、轨道终止、AudioContext 挂起等均有明确错误状态，不得仍显示“正在收音”。

暂停时停止采集、停止上传新的音频、妥善处理模型最后一段输出。暂停期间不得继续偷偷录音或把暂停音频补进最终录音。继续时恢复同一课堂并保持全局音频时间轴连续。

结束需要二次确认，随后停止采集，完成上游会话收尾并释放连接和业务录音权，保存尾句，进入录音归档处理。归档状态至少包含待处理、处理中、可播放、失败；失败可重试，字幕仍可阅读。

结束状态与媒体处理完成分离，不能因为转码耗时而让麦克风继续工作。

## 七、录音权转移、申请与离线接管

### 1. 三种不同权限

明确区分：账户角色、课堂业务收音权、浏览器设备麦克风权限。

业务收音权可以由网站转移；浏览器权限只能由目标设备的用户授权，网站不能把 A 设备的授权“复制”给 B 设备。

### 2. 主动转移

收音者点击字幕区域上方的小人图标，弹出“转移录音权”。列表仅包含当前课堂在线且有效的普通用户/管理员，排除游客、禁用账户与尚未完成强制改密的账户，不暴露学号。

选择目标后再次确认，发送后显示“转移邀请已发送”。目标设备弹窗明确说明“谁希望把录音权转移给你”，提供“接受”“拒绝”。

邀请支持取消、超时和失败提示。接受后在必要时请求目标设备麦克风授权，目标设备准备完成后由服务端原子切换收音者；权限被拒绝或设备不可用时，转移失败，旧持有者仍有效。

旧持有者在切换成功前继续有效；成功后旧设备立即停止发送，服务端同时拒绝旧凭据的新音频，不依赖旧页面是否执行停止代码。全班收到录音者变更事件。原课堂暂停时，转移后仍保持暂停。

### 3. 主动申请

普通用户点击“申请录音权”并确认后，当前收音者收到申请弹窗，显示申请人及“同意”“拒绝”。同意后使用同一设备准备与原子交接流程。

对并发申请采取明确策略：可以展示多个申请，但只有基于当前有效持有状态的一次操作能够成功；过期申请自动失效，不得两个申请人同时获得权利。

### 4. 唯一性和恢复

- 任意时刻，每课堂最多一个有效收音设备连接，而不仅是一个用户名。
- 使用服务端租约、心跳、连接身份及递增 `recorder_epoch` 等机制，音频包绑定课堂、连接、epoch 和序号。旧 epoch 的新音频必须被拒绝。
- 同一账户同时开多个标签页/设备不能重复收音。
- 心跳间隔、离线宽限与邀请超时使用可配置默认值并说明。
- 暂时断线保留合理恢复窗口；窗口过后显示“收音者离线/等待接管”。当前持有者确认失效后，合格用户可经确认接管空缺录音权，由服务端原子裁决并审计；管理员也可强制释放失效权利。
- 不随机分配收音者，不自动开启其他人的麦克风。
- 转移、接管、用户禁用、退出和课堂结束时，都使不再有效的邀请与上传凭据失效。

## 八、音频链路和 Qwen 接入

### 浏览器采集

使用 `getUserMedia` 和 AudioWorklet 等适合实时处理的浏览器能力采集音频。基于实际采样率重采样，规范化为模型要求的单声道 PCM；当前默认链路采用 16 kHz、16-bit PCM。不要只设置一个约束便假定浏览器真的输出了所需格式。

浏览器到本站网关优先传输小尺寸二进制音频帧；网关按 Qwen 文档封装上游请求。不能将 WebM、MP4、Opus 容器字节直接当作 PCM。

对队列长度、帧大小、发送速率与内存缓存设上限，处理背压；异常网络下不无限累计音频造成内存膨胀。转换、上传与广播路径需监测延迟。

### Qwen 版本要求

必须查看本文末尾官方链接，按 Qwen3.8 对应参数实现。不要照搬 Qwen3、Qwen3.5、其他 Realtime 模型或普通 Chat Completions 的参数和事件结构。

首版主要约束：

- 模型 ID：`qwen3.8-livetranslate-flash-realtime`。
- 输出配置使用 `session.output_modalities = ["text"]`。
- 目标语言配置使用 `session.translation.language`。
- 课程术语映射使用官方支持的 `session.translation.corpus.phrases`，验证接口实际接受的数量和长度限制。
- 处理源文的 `conversation.item.input_audio_transcription.delta` 和 `conversation.item.input_audio_transcription.completed`。
- 处理译文的 `response.text.delta` 以及当前版本规定的终结事件；结合 `response.done` 的真实状态区分完成、失败和未完成。
- 上游会话结束时按协议发送 `session.finish`，等待 `session.finished` 或进入有界超时恢复流程，避免直接断开丢掉尾句。
- 不假设源文 item ID 与译文 item ID 完全相同，不强行假定源文、译文始终一对一成句。使用协议实际提供的关联信息，保存映射和时间精度；缺失的信息不得伪造。
- WebSocket Endpoint、地域、Workspace ID 与密钥必须匹配；所有上游密钥仅在服务端使用。

为模型建立独立 Adapter，负责鉴权连接、音频转换、配置、事件归一化、错误处理和资源释放。业务层不直接依赖供应商原始 JSON。记录当前课堂使用的非敏感配置版本。

处理鉴权失败、权限不足、限流、额度不足、输入格式错误、超时、连接关闭与服务器异常；不得默默切换其他模型或用模拟文本掩盖失败。

验证真实会话时长与限制，按实际限制安全轮换。不能假定一条上游连接可以无限持续，不能假装供应商一定支持断点续接或任意历史上下文注入。

## 九、流式字幕、逐句展示与协作修正

每个字幕单元包含相对课堂录音时间、原语言文本、目标语言译文与状态。默认译文突出、原文次要，允许仅译文/仅原文/双语切换。

流式到达时即时更新同一个临时单元，不把每个增量另建为一句。使用稳定单元 ID、响应关联和序号去重，不能因重连或重复事件不断重复追加相同字幕。

按实际语句边界展示“一句一段”。不能简单按每个英文句点断句，必须覆盖缩写、小数、单位和专业术语。没有精确对齐时采用可解释的分段策略，不伪造字词级时间戳。

只有相应字段已完成时才允许校对；失败/中断结果必须显示其状态，不把未完成结果标为模型确认完成。

### 校对操作

已完成句子后对普通用户和管理员显示铅笔图标。点击打开编辑弹窗，可分别编辑原文与译文，显示保存/取消。

保存后全班同步更新。原始识别和原始译文不可被覆盖。每次修改追加历史，至少记录句子、字段、修改前内容、修改后内容、修改人、时间和版本号。

改过的句子后增加逆时针历史图标。点击打开历史弹窗，显示原始识别内容、原始译文、谁在什么时间将什么改成了什么，按时间排列。

允许有权限用户恢复某个历史版本，但恢复本身必须形成新记录，不能删除中间历史。模型后续补发的结果不得覆盖人工校对值。

使用乐观锁/version 校验解决同时编辑：冲突时明确返回冲突并展示新版本，不采用无提示的最后写入覆盖。

修改原文后不默认自动重翻译或覆盖已有人工译文。重新翻译仅作为明确的后续操作，并提示额外模型调用；首版可不实现自动重译。

### 阅读体验

字幕默认跟随最新内容。用户主动上滑、选择文字、打开校对弹窗或历史弹窗时，不强制拉回底部；显示“返回实时位置”和新消息数量。

提供字号调整、原文/译文显示选项与大字幕模式（投屏字幕模式），具体要求见第十四节。长课堂使用分页或虚拟列表，不能无限增加 DOM 节点。

## 十、断线恢复与消息一致性

观看端断线后自动重连，携带课堂 ID 和最近事件序号，补齐缺失的已确认内容。临时事件过期时，从服务端加载可靠快照与当前临时状态，不依赖浏览器缓存充当真相来源。

服务端广播事件使用清晰事件类型，例如字幕临时更新、字幕完成、字幕修订、课堂状态、在线状态、录音权变化和邀请结果，并包含版本与幂等标识。

最终字幕、人工编辑、课堂状态等重要变更应先可靠落库再对外确认，可采用事务 outbox；Redis Pub/Sub 仅负责通知，不能把消息推送成功当成数据库已经保存。

收音端断线恢复需区分：本站已持久接收的音频、已发送给模型但结果不确定的音频、仅在浏览器缓存中的音频。只有本站明确持久保存后才能发出相应录音确认。

重连后不盲目重放整段历史给模型，不承诺外部接口“严格恰好一次”。对重复包进行序号与校验去重；无法确认是否翻译成功的区间应标记并保留后续修复所需信息。

短暂断线允许有界缓冲；超过上限明确提示并采取安全暂停或标记缺失区间，不能静默丢失后仍显示完整成功。模型故障时可以在有存储容量保障的情况下继续保存原声，但界面必须显示“翻译中断”，不能把音频已保存等同于字幕已生成。

持有权变化后，过期设备不得把晚到音频插回当前时间轴。需要恢复的历史片段走明确、单独鉴权的恢复流程，不绕过实时录音权检查。

## 十一、录音保存、时间轴与课后回放

必须保存课堂原声，而不是仅保存译文、模型生成语音或播放一个无音频的示意控件。

以服务端接收的规范化音频流建立可恢复的分段录音，片段记录课堂、录音 epoch、序号、媒体起止时间、格式、采样数、校验值和存储状态。网关本地暂存使用持久卷或可靠存储，不把容器临时目录当作灾后可恢复来源。

录音边录边分段持久化、异步上传 OSS，不等整节课结束才首次保存。网络、OSS 或转码失败时有有界重试、磁盘容量保护和告警；处理成功前不能向用户展示“全部保存完成”。

所有字幕与回放使用统一的媒体时间轴。暂停时间不计入音频时间；转移设备、重新连接和上游会话轮换后，课堂媒体偏移继续累加。分别保存墙上时间与媒体时间，不能用模型文字返回时刻充当语音发生时刻。

存在丢包或无法恢复的音频区间时，必须明确标记；采用静音占位或跳过并记录映射都可以，但时间轴策略必须统一并有测试，不能让音频与字幕越播越错位。

使用 FFmpeg 对规范化音频封装为经验证可在目标浏览器回放的格式。不同容器/编码片段不能直接字节拼接。保留转码输入和分片清单直到成品验证成功。

历史课堂详情顶部提供真实音频播放器，下方展示字幕，至少支持播放、暂停、拖动进度、倍速和播放时间。点击字幕时间戳跳到相应录音位置；播放时高亮当前段落，可关闭自动跟随。

模型无法提供精确句子边界时，显示近似定位，不伪造精确识别结果。音频尚在处理或处理失败时显示真实状态，字幕仍可查看。

课程/课堂字幕支持中英乌关键字搜索，结果可定位到句子和录音位置。实现正确搜索后再优化索引，不把英文分词当作通用多语言搜索方案。

## 十二、OSS S3 兼容存储

后台至少可设置服务类型、Endpoint、Region、Bucket、Access Key ID、Secret、可选会话凭据、对象前缀和签名链接有效期。

采用 S3 存储适配层，例如经过实际兼容测试的 AWS SDK for PHP/Flysystem S3 方案。阿里云 OSS 必须使用虚拟托管寻址；不能直接照搬 MinIO 的 path-style 配置。签名版本、payload 校验和传输选项必须按所选 SDK 与 OSS 实测，不自制签名算法。

提供“测试连接”，在专用临时对象路径验证写入、读取、HEAD、删除以及签名 GET。另验证分段/大对象处理与 Range 播放。测试不得接触现有课堂对象，失败需说明具体步骤。

生产 Bucket 使用私有访问。数据库保存对象 key、归档状态、大小和校验信息，不把会过期的签名 URL 当永久文件地址。

普通客户端不得获得永久 OSS 密钥。播放前经业务权限检查后签发短期地址，失效后可安全刷新且尽量保留播放进度。配置跨域和 Range 访问，不能公开列出整个 Bucket。

OSS 上传、删除、转码任务不阻塞音频网关事件循环；数据库与对象存储之间使用可重试的状态流转处理部分失败。

配置修改采用版本化：已经录制和正在上传的对象保留其存储配置引用；切换 Bucket/前缀不能造成历史文件突然无法访问，不能让进行中的课堂在不知情时中途切换存储。

## 十三、管理员后台

后台同样适配手机、平板、电脑并完整支持三语言。

### 课程管理

创建、编辑、排序、启用/停用、归档课程；管理说明、默认目标语言、游客访问方式、分享链接与专业术语表。删除操作有确认和依赖提示，不允许无提示清空全部关联课堂。

### 课堂管理

搜索、筛选、排序、重命名、查看状态与时长，查看当前收音者、结束课堂、检查录音状态、重试归档任务、冻结/解除字幕编辑。管理课堂级分享令牌的撤销、重置及可选有效期；提供字幕导出和导出任务状态。支持受控的软删除与恢复；不可恢复删除单独确认并执行对象清理。

### 句子管理

按课程、课堂、关键字、是否校对筛选；查看原文、译文、模型原始版本、人工历史与对应录音时间。管理员可以校对、恢复版本或软删除句子，所有操作审计。

### 用户管理和 Excel 导入

支持单个新增、编辑姓名和学号、禁用/启用、重置密码、撤销会话、管理员受控调整角色。

提供真实可下载的 `.xlsx` 标准模板，至少包含“名字”“学号”两列。导入器可以兼容“姓名”等明确别名，不能因模板界面语言不同而无法识别自己的模板。

学号列按文本保存，保留前导零，防止科学计数法和整数精度问题。姓名允许重复，学号必须唯一。对于文件中已丢失前导零且无法可靠恢复的值，提示校验，不擅自猜测。

导入先预检和预览，再确认执行。显示新增、更新、跳过和错误数量，错误对应原文件行号并能下载错误报告。

重复学号默认跳过，管理员可显式选择更新非敏感资料；不得自动重置已有用户密码，不得自动提升角色。批量导入默认只创建普通用户。

初始密码严格使用学号后 6 位，并设置强制改密标记。导入过程不把明文密码写入日志。

校验文件类型、大小、行数、必填字段、空白字符、重复值和异常压缩内容；不执行表格公式或宏。错误报告与导出文件防止公式注入。批量写入支持事务或可恢复分批，不重复导入、不留下无法解释的半完成结果。

### 系统设置

管理模型与 OSS 设置、默认语言/时区、分享策略、录音保存时长、上传限制、单课堂最长时长、并发课堂上限、用量告警和错误日志。

敏感凭据在服务端加密保存，主密钥通过安全环境配置注入并备份；页面只显示脱敏状态，不能通过普通 GET 接口、日志、前端构建产物或错误堆栈泄漏。

Endpoint 等设置要限制协议与允许的目的地址，连接测试防范 SSRF；不得将用户提供的任意 URL 不加校验地交给服务端访问。

## 十四、首版实用增强

### 1. 课程专业术语表

管理员维护源词、目标词、语言方向及可选说明。例如空气动力学课程可维护 airfoil→翼型、angle of attack→迎角、lift coefficient→升力系数。

按已验证的 Qwen 接口传入，不把只在数据库建了表但未参与翻译称为“支持术语优化”。保存课堂开始时的术语版本快照，说明新增术语何时生效。用户人工校对不默认批量改写术语表。

### 2. 每节课二维码分享与大字幕模式（首版必做）

#### 2.1 入口位置与二维码弹窗

每个课堂，也就是每一节课的详情页，右上角都必须有独立的二维码图标。无论课堂是待开始、进行中、暂停还是已结束，无论访问者是管理员、普通用户还是有权观看的游客，都有该入口；不能只在课程列表或管理员后台实现。

点击图标打开标题为“分享课堂”的弹窗，至少显示所属课程名称、当前课堂名称、课堂状态、可直接扫描的二维码，以及“扫描二维码，进入本节课堂”的说明。底部提供“复制链接”“保存二维码”“关闭”。所有固定文案支持中文、英语、乌克兰语，名称等用户内容保持原样。

二维码应清晰、高对比且保留必要留白，不添加遮挡码点的装饰。手机弹窗自适应视口，二维码不被裁切，按钮不溢出。复制失败时提供可手动复制的链接；二维码尚未生成时显示加载状态，失败时提供重试，不能显示无效占位码。键盘焦点、关闭后的焦点返回和可访问名称完整。

二维码在本站前端或服务端本地生成，不把含访问令牌的链接发给第三方在线二维码服务。保存的二维码图片应带课程名和课堂名，名称过长时正确换行，不遮挡二维码；不得夹带学号、登录凭据或模型/OSS 密钥。

#### 2.2 扫码落点：直达具体课堂，而不是泛课程入口

二维码绑定稳定的课堂 ID，指向该节课的直接访问链接。例：在“空气动力学 → 第二节课”页面展示的二维码，扫码后直接进入“第二节课”，不先停留在首页、课程列表或课堂列表。

- 待开始课堂：进入该课堂的等待页面。
- 进行中课堂：先加载已确认字幕及当前流式状态，再加入同一课堂的实时订阅，默认定位到实时位置，不丢失入场前已保存的内容。
- 暂停课堂：显示该课堂已有记录和暂停状态，继续订阅，恢复后正常收到新字幕。
- 已结束课堂：进入同一课堂的录音回放与字幕记录页；是否可播放取决于真实归档状态，不自动播放音频。

课堂改名不会改变二维码对应的课堂。该课程后来创建第三节课，第二节课的旧二维码仍进入第二节课，不得复用“课程当前活动课堂”的自动跳转逻辑。链接失效、课堂删除或权限撤销时明确提示原因，不静默跳到其他课堂。

未登录同学扫码后按游客身份直接观看，不强制登录或注册，不申请麦克风权限。已登录同学保留原会话身份，但扫码不自动取得录音权，也不自动开始收音。课堂链接不会因进入大字幕模式、切换语言或打开二维码而改变绑定对象。

#### 2.3 分享范围与撤销

公开课程可使用该课堂的公开直达链接。仅持链接访问的课程使用不可猜测、可撤销且限定到该课堂的随机访问令牌；可以使用 `/s/{token}` 等独立解析路由。课堂级链接不得自动授予浏览其他课堂或课程全部历史的权限。

公开 URL 与私密分享令牌的撤销语义要分清：撤销随机令牌并不能让一个仍公开可见的课堂自动变成私密课堂。需要停止公开访问时，由管理员修改访问策略，并同步处理当前订阅、回放授权和导出权限。

链接模式默认使用稳定的课堂级观看链接，除非管理员设置有效期或主动撤销/重置，不应每次打开弹窗都生成新令牌或令旧二维码失效。令牌只授予观看能力，不含管理、编辑、收音或字幕批量导出权限，也不能将临时 OSS 签名播放地址当作课堂分享链接。

游客仅能展示/复制自己已经有权使用的该课堂链接，不得因点击二维码而创建新授权、延长授权、提升权限或绕过撤销。需要预置分享令牌时，在有权限的课堂创建或管理员配置流程中完成。管理员可撤销、重置或设置有效期；普通用户和游客不得调用这些写接口。

服务端校验 HTTP 访问、WebSocket 订阅、历史字幕及音频播放的相同课堂访问范围；课堂 ID 或 URL 参数被更换后不能越权。分享令牌避免明文写入日志或传给外部统计、资源服务。打开二维码弹窗或分享链接不应创建新的模型翻译会话。

#### 2.4 大字幕模式

每节课提供明确的“大字幕模式”入口，适配手机横竖屏、平板和笔记本，也适合外接显示屏展示。进入后隐藏与阅读无关的导航和复杂管理按钮，突出原文/译文及最近字幕；保留课堂名称、状态、断线提示与必要时间标记。

提供字号调整，至少覆盖 24、32、40、48、64 CSS 像素等实用档位或等效连续调节；提供“仅译文 / 仅原文 / 双语”选项。字号、显示方式和自动跟随偏好仅作用于当前用户/设备并在本地保存，不改变全班字幕、课堂目标语言或模型调用。

大字幕模式右上角仍保留二维码图标、语言选择和明确的退出入口。支持浏览器全屏时，可通过用户操作进入真正全屏；不可用时退回页面内沉浸布局，功能仍能使用，不能强制打开新窗口。长句和乌克兰语长词应合理换行，不出现整体横向滚动。

默认跟随实时字幕。用户手动查看历史或选择文字时暂停自动跟随，并显示“返回实时位置”和新字幕数量。退出模式后恢复原页面的阅读位置和编辑草稿，不能清空字幕历史。

切换模式、进入/退出全屏、打开二维码、切换界面语言或调节字号，不得重建麦克风采集、录音会话或模型连接，不得导致重复音频上传。收音者使用大字幕模式时仍需保留明确录音状态和可达的暂停/继续操作，录音权交接邀请与故障提示不能被沉浸布局遮蔽。游客只看到观看操作。

### 3. 字幕导出（首版必做）

#### 3.1 入口和权限

每节课详情工具区提供“导出字幕”入口；手机可放在明确的更多菜单中。管理员和完成强制改密、具有该课堂访问权限的普通用户可以导出，不限制为课堂创建者。游客默认没有批量导出权限；课堂分享链接本身不授予导出权限。

权限同时在创建导出任务、查询任务和领取文件时校验，不能仅隐藏按钮。课堂被删除、访问权撤销或账户禁用后，不再签发新的下载权限。使用私有临时文件或受控下载，不能将导出产物永久公开挂在 OSS；已发出的短期下载地址的失效窗口要明确说明。

#### 3.2 导出弹窗

点击入口打开“导出字幕”弹窗，显示课程名、课堂名，并提供以下选项：

- 格式：TXT（`.txt`）、Markdown（`.md`）、SRT（`.srt`）、WebVTT（`.vtt`）。四种格式均需真实可用，不只交付占位按钮。
- 内容：仅原文、仅译文、双语。默认双语；切换不产生额外翻译，不要求已有字幕语言与界面语言相同。
- 文本版本：当前校对结果（默认）、原始模型结果。当前校对结果使用各字段最新已保存的人工修订，没有人工修订的字段使用模型结果；原始模型结果排除人工修改，不能让两个选项导出同一份已覆盖的数据。

默认范围为该节课堂全部可导出的已确认字幕。按钮为“取消”“确认导出”，进行中显示状态并防止重复提交；失败显示原因并可重试，没有可导出内容时禁用确认并说明原因。

#### 3.3 进行中课堂与一致性快照

进行中和暂停课堂也可以导出。以服务端接受导出请求时的可靠字幕/修订快照为准，记录课堂 ID、截止事件或版本、导出选项和生成时间。后续新句子或人工修改不混入已经开始生成的文件，不分批读取不断变化的“最新值”制造前后不一致的结果。

只导出已确认完成的相应文本字段，不把正在流式生成、失败或中断的文本伪装成最终字幕。存在只有原文或只有译文完成的单元时，仅包含真实已完成内容，并在导出结果说明中报告缺失或跳过数量，不编造另一种文本。默认不导出软删除句子和校对者个人资料。

后台任务可以使用固定版本引用或等效快照方案实现一致性。较长导出异步生成，用户可查看任务状态并领取结果；队列任务不得阻塞音频网关。导出过程只读取已有内容，不重新识别音频或请求模型翻译。

#### 3.4 文件内容、时间轴与编码

TXT/Markdown 按课堂媒体时间顺序排列，每段显示时间、所选文本；双语按“原文在前、译文在后”组织。文件头包含课程名、课堂名、课堂创建时间、源语言/目标语言信息（未知时如实标注）、导出时间和所选文本版本，不自动翻译名称或字幕。

SRT/WebVTT 输出合法、可被标准解析器读取的字幕文件，使用字幕段的媒体起止时间，而不是请求时间、模型返回时间或日期时间。暂停不计入媒体偏移；多次暂停、交接和会话轮换后仍与该课堂最终录音时间轴一致。SRT 序号与时间格式、WebVTT 文件头及 cue 结构均需通过解析测试。

双语字幕优先在同一有依据的字幕段内显示原文与译文。没有精确的一一对应时，按已保存的真实关联与时间范围组织，不为了双行效果伪造对齐。时间精度只到段落级时，必须在导出说明中标明近似，不能声称有字词级准确时间。

起止时间缺失、结束早于开始或无法可靠映射到录音的内容，不得随意编造时间来生成“看似合法”的字幕；应显示具体问题，允许先导出 TXT/Markdown，或明确说明有多少段无法纳入带时间格式。不得静默丢失仍显示“完整导出”。

文件统一采用 UTF-8，正确处理中文、英语和乌克兰语，保留 І、Ї、Є、Ґ 等字符及换行。文件名包含课程名、课堂名、日期、语言布局与文本版本，过滤路径字符并兼顾长度限制；下载响应使用正确的文件类型及兼容非 ASCII 名称的文件名处理。

元数据不可破坏字幕格式：TXT/Markdown 可放文件头；WebVTT 使用合法 NOTE；SRT 不插入非标准标题或伪字幕来承载说明，导出时间/版本可在导出结果页和文件名中展示。避免将用户字幕直接作为可执行 HTML 输出。

#### 3.5 导出记录与录音下载边界

记录导出任务发起者、课堂、格式、文本版本、快照截止点、状态及产物到期时间，设置合理的并发、频率和临时文件保留限制。导出记录和文件领取不能通过更改任务 ID 越权访问。

本节必做范围是字幕导出；原声下载仍由管理员通过课程设置单独控制，不因支持字幕导出而自动允许录音下载。普通网页可见内容不声称能够完全防复制；即使隐藏原声下载按钮，也不能声称绝对阻止对已允许播放音频的保存。

### 4. 用量与费用保护

记录每课堂使用的模型、调用时长、官方返回的 token/usage、失败和重试情况。官方未返回的数据只显示为估算，不伪造精确账单。

模型价格按地域、币种、计费项目和生效时间配置；后台区分估算费用与官方最终账单。设置单课堂时长、并发课堂数、日用量和告警阈值，默认不硬编码本提示词未提供的价格。

达到限制后有可解释行为与提前提示，不能无通知地丢掉尾句或持续调用。普通观众切换界面语言、修改字号、刷新或进入历史课堂都不应触发额外翻译。

### 5. 录音告知和数据管理

开始录音前显示用途、共享范围和保存说明，要求发起者确认已经取得必要许可。持续显示明确录音状态。管理员能配置保存周期、导出范围与删除处理。

游客与普通观众不应看到学号、密钥、导入记录或内部诊断详情。公开分享有风险提示。数据删除与保留策略应说明数据库、OSS、备份和审计的处理范围，不声称在所有外部缓存中能够即时彻底抹除。

## 十五、数据模型与工程可靠性

根据实现设计数据库迁移，至少覆盖用户、登录/记住登录设备、课程、课堂、课堂录音租约、交接请求、音频片段、成品录音、字幕单元、字幕修订、课堂事件/事务 outbox、术语、课堂级分享令牌、导入任务、字幕导出任务及快照、用量、设置版本和管理员审计。

关键约束：

- 学号唯一、字符串存储；关系使用外键，状态与时间字段有合理约束。
- 同课程未结束课堂唯一；同课堂有效收音者唯一。
- 字幕单元、音频片段、邀请操作和模型完成事件有幂等键。
- 时间戳使用适当的 PostgreSQL 时间类型，媒体偏移用整数毫秒/采样数，不用浮点累计导致长课堂漂移。
- 原始识别与原始译文、人工修订分开存储。
- 常用课程/课堂排序、字幕查找、用户检索和审计分页有索引。
- 业务查询防止 N+1，不一次返回整学期字幕。
- 日志使用关联 ID 串联课堂、连接、模型会话与任务，默认不记录完整音频、敏感凭据或大段私人字幕。
- HTTP 与 WebSocket 均实施对象级授权、消息大小限制、速率限制和正确的来源校验；防范 CSRF、XSS、SQL 注入和越权。
- 用户生成字幕按文本渲染，不能直接作为 HTML 注入。
- 进程异常时正确恢复状态，数据库、Redis、磁盘或 OSS 不可用时安全失败，不能继续制造无记录的有效录音权。

## 十六、浏览器限制与性能验收

生产必须通过 HTTPS/WSS，localhost 开发例外。麦克风请求必须由合格用户明确操作触发。不得宣称网页能绕过系统权限、锁屏限制或后台挂起。

支持时使用 Screen Wake Lock，并处理释放与重新申请；仍需提示收音设备保持页面前台、避免锁屏和省电中断。PWA 安装不等于获得原生后台录音保证。

检测页面恢复、音频轨道终止、麦克风拔插和上下文挂起。恢复失败时停止虚假“正在录音”状态，通知课堂并进入恢复/接管流程。

设计目标按“一位收音者、约 100 位同时观看者、至少 90 分钟课堂”验证，这些是首版测试目标，不是无条件生产容量承诺。记录测试机器、网络、并发、浏览器版本和测试方法。

分别测量音频上传、本站网关转发、模型响应和观众端广播延迟。不把模型宣传延迟等同于实际端到端延迟，不在未测量时编造实时性指标。

自动化覆盖 Chromium 和 WebKit 等可用环境，并区分真实设备测试与浏览器模拟。特别列出 Android、iPhone/iPad Safari、桌面 Chrome/Edge/Safari 的已验证与未验证情况，不能只在一个桌面浏览器测试后宣称全端兼容。

## 十七、必须通过的功能与异常测试

### 权限与账户

游客可以看允许访问的内容，但通过直接 HTTP 请求、伪造 WebSocket 命令也不能写入或上传音频。普通用户不能进入后台。强制改密不能通过刷新、改 API 或使用旧 Token 绕过。禁用账户与退出全部设备后长连接权限失效。学号前导零保留，重复导入不重置密码、不提升权限。

### 课程与课堂

课程置顶与直达进行中课堂正确，同时能访问完整历史列表。搜索与排序字段、方向有效。两位用户同时创建课堂不会产生同课程两个未结束课堂。重命名对其他在线用户同步。暂停、继续、结束与归档状态边界清晰。

### 收音与交接

覆盖邀请接受、拒绝、取消、超时；多人同时申请；目标拒绝浏览器麦克风；收音者掉线；同用户多设备；切换后旧设备继续恶意发送；管理员接管；转移时课堂结束。始终不出现两个有效录音输入。

### 字幕一致性

同一课堂多个页面同时收到真实源文与译文。模拟重复、乱序与重连，不产生重复最终句子。源文与译文异步到达不会错误覆盖。两人同时校对产生明确冲突。模型原始结果与编辑历史完整保留，人工校对不会被迟到模型结果覆盖。

### 保存与回放

进行长时间录音与多次暂停/交接，上述操作后点击字幕仍能定位到合理录音位置。模型关闭前尾句保存。进程重启、OSS 上传失败、转码失败、签名过期都能正确恢复或报告。归档完成前不展示伪播放成功。

### 国际化和界面

全部页面与弹窗切换三种语言，包含后台和错误信息。乌克兰字符、长姓名与长按钮文字不乱码、不溢出。手机软键盘和安全区不遮挡关键按钮。用户上滑看历史或编辑时不被强制自动滚动。

### 二维码分享和大字幕模式

每节课在三类设备、三种语言和全部课堂状态下都有右上角二维码入口，弹窗中的名称、二维码及复制链接准确对应同一课堂。未登录设备扫码后直达对应课堂，不要求登录、不触发麦克风；有活动课堂的同课程也不能劫持历史课堂二维码。课堂改名和课程新开课堂后，旧码仍进入原课堂；删除、撤销或过期时显示明确提示。

验证课堂级令牌不能访问其他课堂，游客不能生成、重置或延长令牌，公开 URL 与私密令牌的撤销行为符合访问策略。二维码实际解码结果必须等于可用的目标链接，而不是仅验证画面出现图案；验证图片保存和复制失败后的备用操作。

大字幕模式保留二维码、语言和退出入口，字体、原文/译文布局与跟随偏好不影响其他观看者。切换模式或语言、打开二维码不会重启收音、重新调用模型或产生重复上传。手动翻历史不被拉回；收音者仍可暂停，交接邀请可见；不支持真全屏时页面内模式正常工作。

### 字幕导出

真实生成并读取 TXT、Markdown、SRT、WebVTT，覆盖原文/译文/双语与原始/校对两个版本的组合；含中文、英文、乌克兰文和特殊字符。验证校对前后结果不同且原始结果不可变，SRT/WebVTT 可解析且时间轴与暂停、交接后的录音一致；元数据不会变成无关字幕。

验证进行中课堂导出时的新句子与同时编辑不会污染快照；流式未完成段不会被冒充最终段；无内容、部分字段缺失和非法时间范围均有明确说明。长文件任务不阻塞实时字幕，失败可重试，连续点击不产生失控重复任务。

游客伪造 API、其他用户更换任务 ID、下载前账户禁用或课堂权限撤销均不能绕过权限；过期产物安全清理。导出不触发模型识别或翻译，字幕导出权限不自动开放原声下载。

### 安全与部署

扫描前端产物和日志确保不泄漏密钥。验证公开/链接访问切换与分享撤销。数据库备份能恢复到独立测试环境。部署重启后服务可以启动，但不自动开启任何用户麦克风。

### 外部实测诚实性

## 十八、阶段安排与交付物

### 阶段 A：技术风险和纵向闭环

先验证真实 Qwen3.8 连接、文字模式、原文和译文事件、音频格式、收尾行为；验证 PHP S3 客户端与目标 OSS 的签名读写及 Range 播放。随后完成一位用户收音、两位以上用户共享字幕、数据库保存和录音回放。

阶段 A 不要求等待所有后台完成，但工程结构、权限校验和数据持久化必须是真实实现，不能先用完全不同技术搭一个无法迁移的临时 Demo。

### 阶段 B：完整产品功能

完成全部角色、首次改密、90 天保持登录、课程/课堂管理、搜索排序、录音权流程、逐句修订与历史、Excel 模板与导入、三语言和响应式界面，以及每节课右上角二维码分享、大字幕模式和四种格式的字幕导出。二维码必须能实扫直达课堂，导出必须生成真实文件，不能将这三项降级为二期或仅保留按钮。

### 阶段 C：可靠性和课堂体验

完成断线恢复、进程恢复、长课测试、术语表、字幕回放联动、用量告警与部署验收；强化二维码访问撤销、全设备大字幕体验、导出快照一致性和长文件任务的异常测试。

每阶段留下可运行成果、测试结果与未完成项；不要以“下一步可以实现”代替本阶段要求的代码。

## 十九、二期功能：保留扩展点，不默认抢先实现

- 多班级/多课程成员范围与班级级权限。
- 每位学生的私人书签和笔记，不影响全班共享字幕。
- 多个目标语言同时输出，按目标语言共享翻译链路，并明确额外费用与原文映射。
- 基于最终课堂字幕生成摘要、重点和术语卡片，标注 AI 生成，并为结论附课堂时间戳；模型和费用另行配置，不默认认为实时翻译模型可完成所有文本任务。
- 课后上传完整录音补转写、修复网络缺失区间；新版本与人工校对安全合并，不覆盖校对历史。
- PPT/板书图片辅助术语识别与翻译，显式授权上传并说明额外图像费用。
- 译文合成语音、说话人标签等增强；不把自动标签等同于已经验证的真实姓名。
- 邮件激活或一次性初始化凭证、管理员双因素认证。
- 可安装 PWA 与已授权历史文本的离线阅读，但不承诺后台持续收音。
